# PRISM

**Paint the path. Press Play. Hope the unicorn understands the assignment.**

PRISM is a draw-then-play physics puzzle where your only tool is **seven colours of rainbow paint**. Each colour obeys a different rule. Draw your solution, press **Play**, then watch the unicorn walk it on its own.

Reach the gem. Avoid spikes, water and the void. Use less ink to earn a **star**.

## Controls

| Input | Action |
| --- | --- |
| Mouse / finger / pen | Draw |
| <kbd>1</kbd>-<kbd>7</kbd> | Select colour |
| <kbd>Z</kbd> | Undo |
| <kbd>C</kbd> | Clear |
| <kbd>Space</kbd> | Play / Rewind |
| <kbd>Esc</kbd> | Back |

## Seven Colours. Seven Physics.

| Colour | Effect |
| --- | --- |
| **Red** | Bounce |
| **Orange** | Dash |
| **Yellow** | Crumbles after touch |
| **Green** | Walk on walls and ceilings |
| **Blue** | Glide / slow fall |
| **Indigo** | Phase through solid blocks |
| **Violet** | Flip gravity |

Paint has **weight** too: unsupported strokes fall when the simulation starts. Build ramps, hanging shelves, collapsing bridges and chain reactions.

## Modes

**40 hand-made levels** teach the colours one by one, then combine them into harder puzzles.

**Daily** gives everyone the same generated challenge each day.

**Online** is a best-of-three race: everyone solves the same level at once, and the first unicorn to reach the gem wins.

## Paint the Music

The rainbow is also a musical scale. Every colour is a note, and the strokes you draw become the level's melody. When the unicorn touches your paint, those notes play again from its position.

**Draw the solution. Write the soundtrack. Get the unicorn to the gem.**
